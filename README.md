# Extinction Overley

Instaladores e atualizações oficiais do Extinction Overley para Windows.

## [⬇ Baixar instalador para Windows — versão 0.6.0](https://github.com/Pyxsz/extinction-overley-releases/releases/download/v0.6.0/ExtinctionOverley-Setup-v0.6.0.exe)

Clique no link acima para baixar o arquivo `.exe`. Depois, abra o instalador e siga as etapas.

[Ver a versão mais recente e suas novidades](https://github.com/Pyxsz/extinction-overley-releases/releases/latest) · [Todas as versões](https://github.com/Pyxsz/extinction-overley-releases/releases)

### Como usar

1. Instale e abra o Extinction Overley.
2. Vincule sua Steam pela opção do aplicativo.
3. Use o The Isle em **janela sem bordas** para exibir a sobreposição.
4. Abra a engrenagem para configurar os atalhos, os sinais vitais e as skins.

### Próximas atualizações

A partir da versão 0.6.0 instalada, o aplicativo consulta o GitHub e avisa quando há uma nova versão. Em **Configurações → Atualizações**, você escolhe quando baixar e reiniciar para atualizar.

Quem usa uma versão anterior precisa instalar a 0.6.0 uma vez para habilitar esse recurso.
